## How I build

I start with the workflow, ship the smallest useful end-to-end feature, put it
in front of users, and improve it from evidence. Coding agents are part of my
toolkit, while product decisions, architecture, verification, and customer
context stay firmly in the loop.

When a task repeats, I turn it into a documented, testable workflow.
